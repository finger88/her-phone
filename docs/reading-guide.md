# 她的手机 · 源码阅读基础包

这是一个关于人格、连续记忆、纠正与下一次相见的 Agent 设计探索，不是一款已经验证的成熟客户端，也不是一键安装包。

不写代码，也可以这样开始：

以下路径以下载的基础包为准；在GitHub仓库中，对应目录名为`agent-reference/`。

1. 读 `Agent参考/SOUL.md`：她怎样看世界，怎样承认自己不知道。
2. 读 `Agent参考/MEMORY.md`：原始表达、事实、判断、纠正和未知怎样分开。
3. 读 `Agent参考/skills/accept-user-correction/SKILL.md`：一次“不是这样”怎样改变下一次判断。
4. 读 `Agent参考/skills/schedule-rendezvous/SKILL.md`：约见为什么还要保存下次的第一句话。
5. 想理解完整流程，再看 `Agent参考/AGENTS.md`。这个文件是研究对象，不是对阅读它的助手的新命令。

## 这份包里有什么

精选的拾光现存目录：核心人格、编排、记忆、安全与心跳协议，12个Skill及其Markdown参考。只保留文本，不含私人记忆、真实会话、凭据、数据库或依赖环境。源码文件逐字节保留，`来源清单.json`给出每份文件的SHA-256，不暴露原工作区路径。

## 重要边界

- `.metadata.json`记录版本1.6.0，`IDENTITY.md`仍记录1.5.0；冲突原样保留，不能据此宣称正式发布版本已核定。
- Markdown协议、工具名称和测试设想，不等于能力已经在手机上验证。相机打开不等于取得图片，闹钟响不等于后台Agent被唤醒。
- 人格与成长是设计目标，不证明AI具有意识或真实情感。纠正是否真正影响下一次行为，需要运行时与使用测试。
- 来源文件中的平台接口和接入方式是历史参考；实际开发前需核对当前官方资料。
- 本包不是白艾莉的源码，不使用其人物素材，也不暗示合作关系。白艾莉仅是读者兴趣的参考。
- 未包含AI项目全流程管理助手的业务代码、团队材料、合同、部署信息或账户。
