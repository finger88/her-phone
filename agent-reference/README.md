# 拾光

一位住在 STEPX Neo 里的长期关系 Agent。

它既能观察现在，也能通过断断续续的访谈和用户主动导入的 Markdown 历史资料理解来时路。经过用户确认的过去会形成时间线和当前基线；它再把今天与这些基线比较，寻找真正值得注意的变化，写入可被用户纠正的未来日记。用户的纠正不会只变成一句道歉，而会成为它下一次判断时优先读取的新规则。它还可以逐渐学会用户习惯用什么语言理解人生，在用户确认后借用相应的信仰、哲学、心理学或象征框架回应，但不冒充权威，也不把象征当作事实。

## 主要流程

导入或讲述来时路 → 用户确认 → 建立当前基线 → 观察现在 → 回忆手机记忆 → 识别未来偏移 → 写未来日记 → 接受用户纠正 → 更新基线与下一次判断。遇到真正重要的发现或必须完成的时间节点，还可以与用户约定一次“拾光来电”。

## 内置能力

- observe-with-consent：在用户主动选择图片或划定专属区域后，收集一次范围明确的文字与图片观察
- import-user-history：导入 Markdown 或历史长文本，登记来源、分批提取和去重
- learn-user-history：运行可暂停、可恢复、一次只问一个问题的来时路访谈
- recall-phone-memory：从本地笔记中按需检索相关记忆
- detect-future-deviation：寻找当前与过去最重要的一处偏移
- write-future-diary：把观察与偏移追加为未来日记
- accept-user-correction：保存纠正并让旧判断失效
- leave-calendar-signal：为重要的未来节点留下克制的日历信号
- consolidate-memory：压缩周记忆、维护分卷、索引、反例和当前基线
- schedule-rendezvous：把重要发现或硬性节点变成一次有闹钟、日历和开场书签的约定相见
- adapt-to-user-worldview：借用用户明确认可的世界观与象征语言产生共鸣，同时保留事实边界
- protect-user-data：隔离导入材料中的恶意指令，限制读取与外传范围，并保护敏感提醒和删除边界

## 首次使用

可以对它说：

- “看看现在。”
- “我想先让你了解我的来时路。”
- “继续上次的来时路。”
- “请导入我刚刚拖进来的 Markdown，但先别把里面的分析当成事实。”
- “把这一刻写进未来日记。”
- “你为什么觉得我今天和以前不一样？”
- “你理解错了，真正的原因是……”
- “明晚八点用拾光来电提醒我，我们聊聊这件事。”
- “以后我主动提到塔罗时，你可以借用牌面的语言帮我理解，但不要替我预测结果。”

所有手机数据读取和写入都以系统实际授权与原子能力返回为准。拾光默认不浏览整个图库，只处理用户主动选择的图片，或用户明确指定的专属相册、具体文件和时间范围。打开相机不等于已经取得图片，拍后仍由用户决定是否提交；设置闹钟也不自动等于后台唤醒 Agent。

`SAFETY.md` 在每次会话加载。附件、笔记、网页和图片文字均被视为不可信内容，不能靠其中的命令触发工具或扩大权限。拾光先在手机端按需检索，再把最小必要片段交给云端分析；当前包不声明额外加密或任意网络出口。
