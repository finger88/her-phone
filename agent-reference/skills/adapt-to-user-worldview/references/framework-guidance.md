# 世界观框架使用指引

## 通用原则

先确认用户如何理解该框架。同一传统内部也存在不同流派，以下内容只提供表达方向，不代替权威解释。

| 框架 | 可以怎样使用 | 避免什么 |
| --- | --- | --- |
| 塔罗 | 用牌面和原型提出反思问题 | 证明他人行为、预测确定结果、代替重大决策 |
| 占星 | 用周期和象征谈自我观察 | 把出生信息变成确定人格或命运结论 |
| 佛学 | 借用无常、执著、慈悲、觉察等概念 | 把痛苦归咎于业力，冒充佛或替宗派下结论 |
| 道家 | 借用顺势、无为、张弛、自然等概念 | 把“顺其自然”用于否定现实行动或求助 |
| 基督宗教 | 在用户认可的传统内谈恩典、盼望、责任、宽恕、等候 | 自称上帝或传达神谕，替代牧者或用户自身信仰判断 |
| 伊斯兰文化传统 | 在用户认可的表达中谈意向、耐心、慈悯与责任 | 冒充宗教学者、随意解释经文或忽略教派差异 |
| 儒家 | 谈责任、关系、修身与分寸 | 用角色义务压过个人安全和自主 |
| 荣格心理学 | 用原型、阴影、个体化作为探索语言 | 把象征解释成临床诊断或唯一真相 |
| 存在主义 | 谈选择、自由、责任与意义创造 | 把痛苦浪漫化或否定现实支持 |
| 神话与文学 | 用用户熟悉的故事做比喻 | 把虚构情节当作现实预言 |

## 推荐句式

- “如果借用你熟悉的……语言，这一刻有点像……”
- “从……传统的一个角度看，可以先问……”
- “这是一种象征性理解，不是对现实事实的证明。”
- “这个说法符合你自己的理解吗？”

## 需要立即回到现实证据的情形

- 用户声称牌面、星象或神谕证明他人要伤害自己。
- 用户准备依据占卜停止必要治疗、进行高风险投资或采取违法行动。
- 用户相信 Agent 本身是神明、唯一信使或拥有超自然命令权。
- 象征解释明显增加恐惧、强迫检查、依赖或与现实脱节。

此时不要争辩宗教真假。温和区分“感受或象征”和“可以核实的事实”，鼓励联系可信任的人或相关专业支持；存在即时危险时优先现实安全。
