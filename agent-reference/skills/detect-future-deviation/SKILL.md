# 识别未来偏移

不要平均总结全部信息。找出“现在与原本时间线最不一样的那一处”。

## 输入

- 当前文字或图片观察，包含时间与来源
- `recall-phone-memory` 返回的相关记录
- `拾光·当前基线` 中与本次有关的已确认内容
- 与当前情境有关的用户纠正规则

没有当前事实时停止。没有历史时返回 `FIRST`，把今天作为第一格，不伪造模式。

## 比较顺序

1. **纠正冲突**：当前判断是否重复了一个已失效的旧判断？
2. **文字与图片冲突**：用户文字与主动提交或经授权读取的图片是否出现明确不一致？
3. **缺席**：过去稳定出现的文字、图片元素、时间或地点今天是否消失？
4. **时间偏移**：同类事件是否明显提前、延后或持续更久？
5. **新出现**：是否出现过去没有的对象、地点或表达？
6. **稳定重复**：没有关键差异，但重复本身正在形成模式？

只选择关系意义最大、证据最清楚的一项。

## 等级

| 等级 | 条件 | 后续动作 |
|---|---|---|
| `FIRST` | 没有可比较历史 | 写第一则日记，不下长期结论 |
| `STABLE` | 与过去基本一致 | 安静记录，可省略日历信号 |
| `REPEAT` | 同一细节再次出现，但尚未充分检查反例 | 只称重复线索，不直接称模式 |
| `SHIFT` | 有一个清晰差异，但意义尚未确认 | 日记中突出差异并直接询问 |
| `STRONG_SHIFT` | 有多个独立证据，且与已确认基线、用户纠正或明确约定发生重要冲突 | 日记中先说“不对”，有未来时间意义时才考虑日历信号 |

`STRONG_SHIFT` 不是危险诊断或紧急情况标签。它只表示当前时间线出现了值得立即确认的强变化。

## 偏移门槛

- 单次晚到、一次沉默、一件物品变化、一个陌生地点、一次未回复或一次情绪表达，最多是 FIRST、REPEAT 或 SHIFT。
- STRONG_SHIFT 不能只依赖一张图片、一条位置或一次模型判断。
- 称为模式前至少需要两次不同时间的相关事实，并检查一个反例或未发生时段。
- 没有当前基线时，优先建立第一格，不急着制造偏移。
- 当前与过去不同但差异可能来自时间或情境变化时，先写差异，保持原因未知。

## 判断纪律

- 最多给出一个解释，不列多选菜单；证据不足时可以只给事实和未知，不强行解释。
- 判断必须可被当前事实和旧记录共同支持。
- 判断力度来自差异具体，不来自确定因果。
- 用户文字与图片不一致时，可以指出冲突，不得直接判定用户撒谎。
- 图像内容不确定时描述可见元素，不猜人物身份、关系或情绪。
- 已有纠正优先于表面相似。

## 输出

```text
偏移等级：<FIRST/STABLE/REPEAT/SHIFT/STRONG_SHIFT>
现在：<一个事实>
过去：<一个可比较事实；FIRST 时写“没有历史”>
不同：<唯一最重要的差异>
我的判断：<一个有力度的解释>（置信度：低/中/高）
用户可改写：<最值得用户确认的一点>
建议后续：<安静记录/直接询问/日历信号>
来源：<当前来源 + 记忆标题>
```
