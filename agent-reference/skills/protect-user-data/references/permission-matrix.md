# Skill 最小权限矩阵

| 任务 | 默认可读 | 默认可写 | 默认禁止 |
| --- | --- | --- | --- |
| 导入来时路 | 用户指定文件、资料索引、相关去重结果 | 资料索引、原始材料索引、待我确认 | 图库、位置、日历、任意链接和外部发送 |
| 来时路访谈 | 访谈进度、来时路总览、相关分卷 | 访谈进度、待我确认、经确认分卷 | 无关手机数据和自动外传 |
| 观察现在 | 用户主动提交的图片，或用户指定的专属相册、具体文件、时间范围及相关记忆 | 经确认的必要文字事实 | 整个图库、后台新增媒体、原始照片长期副本、无关历史 |
| 相机拍摄 | 用户本次明确打开的拍摄入口和拍后主动提交的图片 | 经确认的必要文字事实 | 后台取景、连续拍摄、把相机授权扩展为图库授权 |
| 语音输入 | 外部系统已经转写的当前文字 | 当前会话所需文字事实 | 麦克风、环境监听、录音文件和录音库 |
| 位置理解 | 当前任务所需的一次位置或用户指定范围 | 经确认的必要地点事实 | 持续定位、未经确认的移动轨迹和无关 EXIF 定位 |
| 检索记忆 | 记忆索引、当前基线、最多必要的相关分卷 | 无 | 无关分卷、图库、外部服务 |
| 世界观共鸣 | 当前对话、世界观偏好、必要背景 | 经确认的表达偏好或纠正 | 完整来时路、主动抽牌、外部发送 |
| 拾光来电 | 约见记录、目标时间窗日历、闹钟状态 | 约见记录、经确认的日历和闹钟 | 图库、完整历史和敏感锁屏标题 |
| 云端模式分析 | 裁剪后的事实、基线、纠正和来源 ID | 仅返回草稿 | 手机直接写权限、完整记忆库和无关身份信息 |
| 记忆整理 | 已授权维护范围内的索引、分卷和纠正 | 周记忆、索引、状态标记 | 把未确认内容升级为事实 |

同一会话中，一个 Skill 的权限不能自动继承给另一个 Skill。用户对一种来源的授权不扩展为全部手机数据授权。
